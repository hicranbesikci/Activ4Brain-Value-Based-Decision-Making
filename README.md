# Improvement in Value-Based Decision-Making Through a Combined Cognitive Training and Aerobic Exercise Program (Activ4Brain) in Older Adults

# Overview

This repository contains MATLAB scripts associated with the study "Improvement in value-based decision-making through a combined cognitive training and aerobic exercise program (Activ4Brain) in older adults."

The repository provides code for the behavioral and the computational analysis of probabilistic reinforcement learning performance, including Rescorla–Wagner (Q-learning) model fitting and parameter recovery procedures.

Computational Model

The Q-learning model includes three free parameters:

α_gain: Learning rate for positive prediction errors

α_loss: Learning rate for negative prediction errors

β: Inverse temperature parameter
